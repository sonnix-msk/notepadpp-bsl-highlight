================================================================
  ПОДСВЕТКА КОДА 1С (BSL) ДЛЯ NOTEPAD++
  Инструкция по установке
================================================================

Что это

  Добавляет в Notepad++ подсветку синтаксиса языка 1С:Предприятие
  (файлы .bsl и .os): ключевые слова, строки, числа, комментарии,
  операторы, препроцессор (#Область, #Если, &НаСервере и т.п.).
  Подсветка разборная (по грамматике), а не «по словарю», поэтому
  аккуратная.


Что нужно

  * Windows.
  * Notepad++ версии 8.x, ОБЯЗАТЕЛЬНО 64-разрядный (x64).
    Под 32-разрядный Notepad++ этот пакет не подходит.
    Как проверить: в Notepad++ меню «?» -> «О программе»;
    в заголовке окна будет слово 64-bit.
  * Права администратора — если Notepad++ установлен в Program Files
    (обычный случай). Windows сама спросит подтверждение.


Как установить (3 шага)

  1. ЗАКРОЙТЕ Notepad++, если он открыт.
     (Иначе установщик откажется работать.)

  2. Запустите файл  INSTALL.bat  (двойной клик).
     - Если появится окно «Контроль учётных записей» — нажмите «Да».
     - Дождитесь надписи «Готово! Подсветка установлена».

  3. Откройте Notepad++ и откройте любой файл .bsl.
     Код будет подсвечен.
     (Файл example.bsl из этого архива — для проверки.)


Если Notepad++ установлен в нестандартное место

  Ничего страшного. Перетащите папку Notepad++ прямо в окно
  установщика (или вставьте путь вручную), когда он попросит.


Как проверить, что всё в порядке

  * В меню Notepad++: «Языки» (Language) -> раздел «T» ->
    пункт «treesitter.bsl». Если он там есть — всё установилось.
  * Открытый .bsl сразу раскрашивается.


Как удалить

  Удалите эти две вещи (нужны права администратора):

    1) папку:
       <папка Notepad++>\plugins\TreeSitterLexer

    2) файл:
       <папка Notepad++>\plugins\Config\TreeSitterLexer.xml

  Где <папка Notepad++> — обычно:
       C:\Program Files\Notepad++


Частые вопросы

  «Язык не появился, подсветки нет»
     - Убедитесь, что Notepad++ был ЗАКРЫТ во время установки,
       затем откройте его заново.
     - Проверьте, что Notepad++ 64-разрядный (см. выше).
     - Убедитесь, что открыт файл с расширением .bsl или .os.

  «Установщик пишет, что нет доступа»
     - Нажмите «Да» в окне UAC. Либо запустите INSTALL.bat
       правой кнопкой -> «Запуск от имени администратора».

  «Windows SmartScreen/антивирус предупреждает»
     - Это обычный .bat + .ps1, просто нажмите
       «Подробнее» -> «Выполнить в любом случае».

  «Антивирус ругается на tree-sitter-bsl.dll»
     - Это ложное срабатывание. Файл — скомпилированная грамматика
       (таблицы разбора), не программа. У антивирусов бывает
       эвристический детект на такие маленькие неподписанные DLL.
     - Добавьте папку plugins\TreeSitterLexer в ИСКЛЮЧЕНИЯ
       антивируса — и всё заработает.
     - Подробнее — в разделе «Антивирус и ложные срабатывания»
       в README проекта на GitHub/GitFlic.


Что внутри архива (кратко)

  INSTALL.bat       — запуск установки (двойной клик)
  install.ps1       — сам установщик (ищет Notepad++, копирует файлы)
  README.txt        — этот файл
  example.bsl       — образец кода для проверки
  files\            — файлы, которые устанавливаются:
      plugins\TreeSitterLexer\TreeSitterLexer.dll          (плагин)
      plugins\TreeSitterLexer\TreeSitterGrammars\...        (грамматика BSL)
      plugins\Config\TreeSitterLexer.xml                    (настройка)
